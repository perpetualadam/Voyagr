`voyagr/utils/junction_topology.py` validates an explicit directed ring-node path and traversable outbound branches. It excludes private/ineligible service connections, respects one-way orientation, refuses unresolved conditional/restriction or multiple-outlet ambiguity, and compares a provider exit count with source topology. Matching counts are VERIFIED_AGAINST_SOURCE graph assertions; conflicts provide generic guidance and no exact count. It does not invent counts from angles and is not wired as a replacement for provider routing. Actual installed providers generally lack the stable way/node path needed for this validator; live exit numbering remains provider evidence, not independently verified topology. Existing adapter count/merge/fork and common visual/voice tests remain.

## Reproducible acquisition workflow (local review only)

`scripts/acquire-phase7-osm.py` accepts a small bbox and either a public OSM XML request or `--input` approved XML. It enforces .01° maximum dimensions and a 4 MiB source cap, retains source attribution/ODbL licence, acquisition date, SHA256 revision, bbox, way/version/node identifiers, directional/access tags and via-node restrictions. Unsupported via-way/conditional relations remain marked unsupported. It outputs PARTIAL and never configures production or claims surveyed accuracy.

Example local command: `.venv/bin/python scripts/acquire-phase7-osm.py --input /tmp/approved-extract.osm --bbox=-0.153,51.502,-0.150,51.504 --jurisdiction England --output /tmp/phase7-review.json`.
